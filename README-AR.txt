======================================================================
  حزمة بناء OpenWrt 23.05.5 + Quick Pro مدمج لجهاز ZTE E8822 / E8820V2
  المواصفات المستهدفة:
  - CPU: MediaTek MT7621A (880MHz)
  - RAM: 64MB DDR2 (إعداد خفيف ومستقر بدون تعليق)
  - Flash: Macronix MX25L12835E 16MB SPI NOR (تخطيط Breed 0x50000)
  - Switch: MediaTek MT7530 Gigabit (DSA)
  - WiFi: MT7603 (2.4GHz) + MT7612 (5GHz)
======================================================================

طريقة استخراج ملف السوفتوير (.bin) مجاناً عبر GitHub في دقائق:
1. أنشئ مستودع جديد (Repository) على حسابك في GitHub (يمكن جعله Private).
2. ارفع كل الملفات والمجلدات الموجودة داخل هذا الملف المضغوط إليه.
3. ادخل تبويب Actions -> اختر "Build OpenWrt 23.05.5 Quick Pro (ZTE E8822 / E8820V2)".
4. اضغط "Run workflow" وانتظر حتى ينتهي البناء.
5. حمّل ملف السوفتوير الجاهز:
   openwrt-23.05.5-ramips-mt7621-zte_e8820v2-squashfs-sysupgrade.bin

طريقة التفليش عبر Breed Web 恢复控制台 بأمان:
1. قبل التفليش: ادخل "固件备份" (Firmware Backup) واحفظ نسخة من "EEPROM" و "编程器固件" (Full Flash) على جهازك للاحتياط.
2. ادخل "固件更新" (Firmware Update) -> فعّل خانة "固件" (Firmware) فقط (لا تلمس Bootloader ولا EEPROM).
3. اختر ملف .bin الناتج، وتأكد أن نوع التقسيم (闪存布局) هو "公版 (0x50000)".
4. اضغط "上传" ثم "更新" وانتظر إعادة التشغيل.
5. ستعمل النسخة مباشرة بثيم Quick Pro وكل الـ 12 أداة مدمجة داخل الروم نفسه (حتى لو تم الفورمات لا تنحذف!).
